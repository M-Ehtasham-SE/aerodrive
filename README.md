# RideNext: Vehicle Rental Management System

A modern, full-stack vehicle rental management system built with the MERN-ish stack (MySQL, Express, React, Node.js). This project focuses on a robust relational database design, featuring complex associations, role-based access control (RBAC), and transactional integrity.

## ✨ Key Features
- **Role-Based Dashboards:** Unique interfaces for Managers, Clerks, Mechanics, and Customers.
- **Reservation Wizard:** Intelligent availability checking to prevent double-booking.
- **Contract Management:** Lifecycle tracking from pickup to return.
- **Maintenance Logs:** Real-time health tracking for the vehicle fleet.
- **Rich Analytics:** Revenue and fleet utilization charts for managers.

## 🛠 Tech Stack
- **Frontend:** React, Vite, Lucide Icons, Recharts, Vanilla CSS.
- **Backend:** Node.js, Express, Sequelize ORM.
- **Database:** MySQL.
- **Security:** JWT Authentication, Bcrypt password hashing.

## 📂 Project Structure
- `/client`: React frontend application.
- `/server`: Node.js/Express API and Sequelize models.
- `/server/models`: Database schema definitions.
